# 🔥 AGNIDAWN
### *Indian Mythology Survival Roguelite*

> Survive 20 minutes against the forces of darkness in ancient India. Guard the sacred Agni Kund until dawn breaks.

## Built With
- Unity 2022 LTS + URP (Universal Render Pipeline)
- FMOD Studio (adaptive audio)
- Blender 5.1 (3D art/sprite rendering)

## Game Overview
AGNIDAWN is a top-down roguelite survival game set in the world of Indian mythology. Inspired by 20 Minutes Until Dawn, but with a richer narrative, divine weapons (Astras), mythological bosses (Ravana, Mahishasura, Kali, Vritra), and 5 distinct Indian environments.

## Branch Strategy
